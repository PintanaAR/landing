# _inspiration/

Drop screenshots of landings, sections, or interactions from **other
products** that inform how we think about Pintana — Linear hero, Vercel
feature grids, Stripe pricing, Loom mockups, etc.

These are **vibe references**, not pixel-perfect targets. Claude Code only
looks at them when you point at one explicitly ("match the spacing rhythm of
linear-hero.png").

## Hygiene

- **Gitignored**: the `.gitignore` excludes `design-references/_inspiration/`
  entirely (except this README). Share the actual images via Drive / Notion /
  Slack — do not commit them.
- **Why**: capturing other companies' product UI in a public-facing repo is a
  grey area. Even on a private repo, treat third-party screenshots as
  reference material to be kept out of source control.

## Optional `notes.md`

If a piece of inspiration captures a specific decision worth remembering
("why we picked the indigo accent over teal", "where the AppWindow shadow
heuristic comes from"), write it in a sibling `notes.md` and **commit only
the notes.md**, not the images.
